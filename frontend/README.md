# Sentry Frontend (React + Vite + Tailwind)

## Setup
1. `npm install`
2. Create `.env` with:
   ```
   VITE_API_URL=http://localhost:5000/api
   VITE_WS_URL=http://localhost:5000
   ```
3. `npm run dev`

## Pages
- Dashboard (live KPIs + line chart)
- Charts (line/bar/area)
- Devices
- Wi‑Fi Setup
- More Details (summary)
- Settings
- Auth: Login & Signup
